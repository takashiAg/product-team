# Product Team

Codex / Claude Codeで、マネージャーと22職能のエージェントがプロダクト開発を進めるスキルです。必要な担当だけを呼び、質問・返答・修正を取り次いで、依頼された成果物と検証結果までまとめます。

## インストール

利用先プロジェクトのディレクトリで実行します。スキルは1つなので、名前やブランチの指定は不要です。

```sh
npx skills add takashiAg/product-team
```

導入先は対話形式で選べます。CodexとClaude Codeの両方を指定する場合:

```sh
npx skills add takashiAg/product-team -a codex claude-code
```

全プロジェクトで使う個人用の導入には `-g` を追加します。

## 使い方

Codex:

```text
$product-team マネージャーにオンボーディング改善を任せて。実装と検証まで進めて。
```

Claude Code:

```text
/product-team マネージャーにオンボーディング改善を任せて。実装と検証まで進めて。
```

必要な職能だけを個別に呼ぶこともできます。

```text
$product-team FSだけ呼んで、この商談の提案と次のアクションをまとめて。
$product-team SalesOpsとCS Opsで、受注後の引き継ぎを整えて。
$product-team UXとUIとフロントエンドで画面を改善し、QA設計とQA実行で確認して。
$product-team セキュリティ担当に、権限とテナント分離を確認してもらって。
$product-team テクニカルライターだけ呼んで、実装とQA結果から操作手順をまとめて。
```

Claude Codeでは先頭を `/product-team` に置き換えます。個別指定の場合はホストから担当を直接呼び、不要なマネージャーや全体開発を追加しません。

## 組織

```text
ユーザー ↔ Codex / Claude Code（対話ホスト）
             └─ マネージャー
                 ├─ BizOps / SalesOps / CS Ops
                 ├─ IS / FS / プレセールス / CS / マーケ
                 ├─ PdM / UXデザイナー / UIデザイナー
                 ├─ 設計 / フロントエンド / バックエンド / インフラ
                 ├─ QA設計 / QA実行（打鍵）/ セキュリティ / データ分析
                 └─ テクニカルライター / 事業責任者 / 経営者レビュー
```

全職能がマネージャー直下です。さらに下位の組織は作らず、元の対話ホストから孫までに留めます。担当間で直接通信できない場合は、マネージャーまたはホストが問いと返答を取り次ぎます。

| 分担 | 責任 |
| --- | --- |
| IS・FS / SalesOps | 見込み客・商談への実働 / 営業プロセスやCRM運用の仕組み |
| CS / CS Ops | 顧客ごとの導入・活用・更新支援 / 支援手順・検知・引き継ぎの仕組み |
| BizOps | 部門をまたぐ業務フローと指標、受け渡し |
| UX / UI | 課題・導線・操作フロー / 画面・見た目・コンポーネントと状態 |
| QA設計 / QA実行 | 受入条件から再現可能なケースを設計 / 実操作と証拠の記録 |
| テクニカルライター | 実装と検証結果から仕様・操作手順・FAQ・リリースノートを作成 |
| 事業責任者 / 経営者 | 事業・戦略の観点からレビュー。実在の責任者の決裁権を代替しない |

詳しい責任・成果物・受け渡しは[職能一覧](skills/product-team/references/catalog.md)にあります。

## 動作の仕組み

`product-team` 一式に職能定義を同梱し、ホストの汎用サブエージェントへ役割・文脈・編集範囲を渡して起動します。カスタムエージェント設定の変更や、別のインストーラーは不要です。ネイティブの `/agents` 一覧へ23人を登録する方式ではありません。

同時実行数と孫を起動できるかは環境に合わせます。孫を起動できない場合はホストが担当の起動を代行し、結果をマネージャーに返します。委任そのものがない環境では単独で進め、その制限を明示します。

QA実行は既存のPlaywrightや利用可能なブラウザツールを使います。このスキル自体はブラウザやMCPサーバーをインストールしません。ケースごとの操作・期待結果・実測・必要なスクリーンショットなどを記録し、実行できないものは未実行として報告します。
